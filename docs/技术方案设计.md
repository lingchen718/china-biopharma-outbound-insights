## 1. 目标与范围

本文档基于已定稿的产品设计文档与可运行 demo，给出从「已清洗 CSV」到「可检索、可分析的 Web 情报平台」的工程实现方案。

**范围（MVP）**：

- 7 个分析页面 + 生态网络方块 + 交易卡片 + 全局过滤器。
- 数据覆盖 2019–2026，金额归一化为 M USD。
- 只读平台，无账户体系；暗色主题；中英双语。
- 前后端分离但同仓库（monorepo）部署。

**不包含**：原始数据采集/清洗流水线、实时行情、账户权限、导出能力（列入后续迭代）。

## 3. 数据层设计

### 3.1 表结构（PostgreSQL DDL）

```sql
-- 枚举 lookup：统一英文规范名、中文别名、排序、固定配色
CREATE TABLE lookup_dim (
  dim         text NOT NULL,           -- modality | indication | stage | deal_type | region
  key         text NOT NULL,           -- 英文枚举键
  label_en    text NOT NULL,
  label_zh    text NOT NULL,
  sort_order  int  NOT NULL DEFAULT 0,
  color       text,                    -- 分类色（modality/region 等）
  PRIMARY KEY (dim, key)
);

CREATE TABLE companies (
  id          bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  name        text NOT NULL UNIQUE,    -- 展示名（可含中英）
  name_en     text,
  country     text,
  region      text,
  is_chinese  boolean NOT NULL,        -- 中国授权方 / 海外引进方
  aliases     text[]
);

CREATE TABLE assets (
  id           bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  drug_name    text NOT NULL UNIQUE,
  drug_name_en text,
  target       text,
  modality     text,
  indication   text,
  latest_stage text
);

CREATE TABLE deals (
  deal_id            text PRIMARY KEY,          -- 唯一 Transaction ID
  signing_date       date NOT NULL,             -- 签署日期（统计口径）
  announce_date      date,
  licensor_id        bigint REFERENCES companies(id),
  licensee_id        bigint REFERENCES companies(id),
  asset_id           bigint REFERENCES assets(id),
  target             text,
  modality           text,
  indication         text,
  deal_type          text,
  stage              text,
  upfront_musd       numeric(14,2),             -- 归一化首付款（M USD）
  total_value_musd   numeric(14,2),             -- 归一化潜在总额（M USD）
  milestone_musd     numeric(14,2),             -- total - upfront，可拆分时
  milestone_derivable boolean,                  -- false → Not Derivable
  value_disclosure   text,                      -- Full / Partial / Undisclosed
  confidence         text,
  region             text,
  currency           text,
  fx_rate            numeric,
  source_name        text,
  source_title       text,
  source_url         text,
  publish_date       date,
  analyst_note       text,
  ingest_batch       text NOT NULL,
  created_at         timestamptz DEFAULT now()
);

CREATE TABLE deal_territory (
  deal_id   text REFERENCES deals(deal_id) ON DELETE CASCADE,
  territory text,                              -- 具体国家/地区
  region    text,                              -- 上层区域汇总
  PRIMARY KEY (deal_id, territory)
);

CREATE TABLE ingest_run (
  id          bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  batch       text NOT NULL,
  source_file text,
  started_at  timestamptz DEFAULT now(),
  finished_at timestamptz,
  rows_total  int,
  rows_upsert int,
  report      jsonb
);
```

**索引建议**：

- `deals(signing_date)`：时间趋势与年份过滤。
- `deals(modality) / indication / deal_type / stage / region / confidence`：单列过滤与聚合。
- `deal_territory(region, territory)`：地图与区域过滤。
- `companies(is_chinese)`：排行榜与网络。
- 可选：`deals(modality, signing_date)`、`deals(stage, deal_type)` 等组合索引服务于高频矩阵聚合。

**口径说明**：

- 金额统一 M USD；直接采用 CSV 已按交易当日汇率折算的 `upfront_musd`/`total_value_musd`，`currency`/`fx_rate` 仅作审计与一致性参考，不重复折算。
- `milestone_musd` 仅在「首付款与潜在总额对价范围一致、可拆分、两端均已披露、无股权/分成等无法拆分对价」时派生，否则 `milestone_derivable=false`（Not Derivable）。
- 未披露金额以 NULL 存储，严格区分「披露为 0」与「未披露」。

### 3.2 ETL（Python）

```
CSV(26 列)
  │ 1. 校验 26 列、deal_id 唯一、日期格式
  ▼
规范化
  │ 2. 枚举规范化（modality/indication/stage/deal_type/region）→ lookup 校验
  │ 3. 金额校验：采用 upfront_musd / total_value_musd（已按交易当日汇率折算）
  │ 4. milestone 派生（满足条件才计算，否则 Not Derivable）
  │ 5. territory 拆分 → deal_territory（多行）
  ▼
PostgreSQL upsert
  │ 6. deal_id 幂等（INSERT ... ON CONFLICT DO UPDATE）
  │ 7. 同步 companies / assets / deal_territory
  ▼
质量报告
      8. 行数、披露率、置信度分布、缺失值、source_url 校验结果 → ingest_run.report
```

ETL 以 `ingest_batch` 幂等，可重复执行；失败可回滚到上一批次。

## 4. API 层设计

### 4.1 约定

- Base URL：`/api`
- 请求：`GET` 只读；过滤条件统一为 query 参数。
- 响应：`{ "data": ..., "meta": { "total": n, "disclosure_rate": x } }`
- 金额单位统一 M USD（展示层再格式化为 $M/$B）。
- 通用过滤参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `year_from` / `year_to` | int | 签约年份区间 |
| `deal_type` | 逗号分隔 | 交易类型 |
| `modality` | 逗号分隔 | 药物形式 |
| `indication` | 逗号分隔 | 治疗领域 |
| `stage` | 逗号分隔 | 研发阶段 |
| `region` | 逗号分隔 | 上层区域 |
| `disclosure` | full/partial/undisclosed | 披露状态 |
| `q` | string | 公司/资产/靶点/治疗领域关键词 |
| `sort` / `order` / `page` / `page_size` | — | Explorer 表格 |

### 4.2 端点清单

| 方法/路径 | 用途 | 对应页面/模块 |
| --- | --- | --- |
| `GET /api/deals` | 分页/过滤/搜索/排序交易列表 | Explorer、最近交易 |

## 6. 页面实现方案

### 01 市场概览 Market Overview

- KPI 卡片（交易笔数 Total Deals、披露总额、最高单笔、首付款、中国授权方 CN Licensors、海外引进方 Overseas Licensee）。
- 交易活跃度趋势（指标：Deals/Upfront/Total；维度：Modality/Indication/Stage/Region）。
- 全球足迹：按 territory 国家粒度，交易笔数降序 Top8；点击以 region 全局筛选。
- 最近交易表（跳转 Explorer）。

### 02 交易格局 Deal Landscape

- 四个维度：按研发阶段 / 按技术类型 / 按治疗领域 / 按交易类型。
- 每维成对环形图：左 `Counts of Deals`、右 `Sum of Upfront Payments`；中心显示分母总量。
- 金额占比仅统计已披露首付款；标注 `Upfront disclosed for X% of deals`。
- 每维 `关键发现 / Key Insight`（数量占比最高、金额占比最高、数量与金额占比差距最大）。

### 03 交易金额 Deal Economics

- 快照 KPI：已披露首付款笔数、已披露首付款总额、中位数、已披露总额笔数、潜在总额。
- **Deal Activity & Value Trends**：三张柱形图 + 全局粒度（Year/Quarter/Month）+ YoY；Quarter/Month 按年份分色；点击柱 → Explorer 应用年份筛选。
- 金额分布：按 modality 箱线图（P25/Median/P75）。
- 交易金额探索：气泡图（面积=首付款、颜色=modality、形状=deal type、jitter）。
- 里程碑分析：`Largest Disclosed Milestone Packages` + Not Derivable 说明。

### 04 技术与管线 Modality & Pipeline

- **市场热点 Market Hotspots**：Target/Modality Top10 排名、Modality 应用广度表、Target × Modality 热力图（指标可切换：独立交易笔数 / 去重资产数）。
- **交易价值 Deal Value**：按 Modality 金额箱线图（仅已披露）+ Target × Modality 价值气泡图（大小=独立交易笔数、颜色=中位总金额或首付款中位数）。
- **时间趋势 Time Trends**：Modality 年度活跃度折线 + 年度占比 100% 堆叠面积 + 近期增长表。
- **研发成熟度 Development Maturity**：Modality × 阶段堆叠条形图（笔数/资产切换）+ 阶段 × 金额箱线图。
- **综合机会矩阵 Opportunity Matrix**：Target × Modality 热度—价值—增长散点图（四象限参考线）。
- **资产管线 Asset Pipeline**：资产表（关联交易金额，标注多资产不可求和）。

### 05 治疗领域 Therapeutic Areas

- Disease Area Trends、Indication Hotspots、Deep Dive（单领域下钻药物形式/阶段/公司）。

### 06 交易参与方 Companies

- 中国授权方 / 海外引进方排行榜（多指标排序）。
- 公司 × 药物形式气泡（大小=笔数、颜色=modality）。
- 生态网络 Network（力导向图，节点=公司、颜色区分中/外、大小=笔数）。

### 07 交易数据库 Transaction Explorer

- 搜索 + 过滤 + 全量表 + 交易卡片（Deal Card：中英双语字段 + 信源 + 置信度 + 分析师备注）。

## 7. 关键聚合 SQL

### 7.1 总览 KPI

```sql
SELECT
  count(*)                                        AS total_deals,
  count(*) FILTER (WHERE total_value_musd IS NOT NULL) AS disclosed_deals,
  sum(total_value_musd)                           AS total_value,
  sum(upfront_musd)                               AS total_upfront,
  max(total_value_musd)                           AS highest_deal,
  count(DISTINCT licensor_id)                     AS licensors,
  count(DISTINCT licensee_id)                     AS licensees
FROM deals
WHERE signing_date >= :d0 AND signing_date <= :d1;
```

### 7.2 时间趋势 + 同比（Activity & Value Trends）

```sql
WITH base AS (
  SELECT
    date_trunc(:gran, signing_date) AS period,   -- year/quarter/month
    count(*) AS deals,
    count(*) FILTER (WHERE upfront_musd IS NOT NULL) AS up_n,
    sum(upfront_musd) AS upfront,
    count(*) FILTER (WHERE total_value_musd IS NOT NULL) AS tot_n,
    sum(total_value_musd) AS total_value
  FROM deals
  GROUP BY 1
)
SELECT
  period,
  deals,
  upfront,
  total_value,
  up_n,
  tot_n,
  lag(deals)    OVER (ORDER BY period) AS prev_deals,
  lag(upfront)  OVER (ORDER BY period) AS prev_upfront,
  lag(total_value) OVER (ORDER BY period) AS prev_total
FROM base
ORDER BY period;
```

YoY 在服务层计算：`(cur - prev)/prev*100`；`prev` 为 0 或 NULL 时返回 N/A。

### 7.3 成对环形图（Landscape）

```sql
-- counts
SELECT :dim AS key, count(*) AS value FROM deals GROUP BY 1;
-- upfront（仅披露）
SELECT :dim AS key, sum(upfront_musd) AS value
FROM deals WHERE upfront_musd IS NOT NULL GROUP BY 1;
```

### 7.4 箱线图四分位（Distribution）

```sql
SELECT modality,
  min(total_value_musd) FILTER (WHERE total_value_musd IS NOT NULL),
  percentile_cont(0.25) WITHIN GROUP (ORDER BY total_value_musd),
  percentile_cont(0.50) WITHIN GROUP (ORDER BY total_value_musd),
  percentile_cont(0.75) WITHIN GROUP (ORDER BY total_value_musd),
  max(total_value_musd) FILTER (WHERE total_value_musd IS NOT NULL)
FROM deals
WHERE total_value_musd IS NOT NULL
GROUP BY modality;
```

### 7.5 气泡图

```sql
SELECT deal_id, stage, modality, deal_type, upfront_musd, total_value_musd,
       licensor_id, licensee_id, indication, region
FROM deals
WHERE total_value_musd IS NOT NULL;
```

气泡面积 = `2 * sqrt((40 + upfront_musd * 4) / PI)`；X 轴加 jitter。

### 7.6 网络图

```sql
-- 节点
SELECT c.id, c.name, c.is_chinese, count(*) AS deals
FROM companies c
JOIN deals d ON c.id IN (d.licensor_id, d.licensee_id)
GROUP BY c.id, c.name, c.is_chinese;
-- 边
SELECT licensor_id AS src, licensee_id AS dst, count(*) AS deals,
       sum(total_value_musd) AS value
FROM deals GROUP BY 1,2;
```

## 10. 安全与性能

- 只读 API，全部参数化 SQL，禁止拼接；限制 `page_size` 上限。
- 金额/日期等聚合尽量由 SQL 下推，前端不拉全量。
- 高频聚合可物化视图或 Redis 缓存；`deals` 按年份分区（可选）。
- 数据追溯：交易卡片展示 source_url、publish_date、confidence、analyst_note。
